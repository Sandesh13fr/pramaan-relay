# Message experiment

## Hypothesis

Because judges have less than a minute to understand the process change, we believe a direct state distinction in the hero will increase correct answers to “Does generated mean accepted?” compared with the narrative control.

## Variants

- Control: `/` uses “A life certificate should not die between systems.”
- Variant: `/?variant=direct` uses “Generated is not accepted. The handoff still needs an owner.”

Only the hero headline changes. Assignment is URL-based so the Round 1 prototype uses no cookies, persistence, analytics, or personal data.

## Measurement plan

- Primary: percentage answering the one-minute understanding check correctly.
- Secondary: scenario start and receipt inspection rates.
- Guardrails: flow completion, mobile error rate, and reviewer reports of policy confusion.
- Do not call a winner before the pre-committed sample size is reached. At a 10% baseline and a 50% minimum detectable lift, the skill reference suggests roughly 550 observations per variant as a planning estimate.
